# ذهن تریدر 2.3 — بازطراحی ظاهری

این بسته، ظاهر نسخه وب ذهن تریدر را با الهام از تصاویر ارسالی بازطراحی می‌کند: زمینه سرمه‌ای بسیار تیره، کارت‌های گرد، تأکید سبز فیروزه‌ای، نوار ناوبری پایین موبایل و آیکون اختصاصی حلقه‌ای.

## محتویات

- `index.html` — برنامه اصلی با رابط بازطراحی‌شده
- `manifest.webmanifest` — مشخصات نصب PWA با مسیرهای نسبی مناسب GitHub Pages
- `sw.js` — Service Worker با نسخه کش جدید و به‌روزرسانی shell
- `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — آیکون‌های برنامه
- `Code.gs` — پل Google Apps Script برای خواندن شیت Journal؛ فقط در Apps Script استفاده شود
- `DEPLOY_FA.md` — راهنمای انتشار روی GitHub Pages

## انتشار روی GitHub Pages

1. قبل از جایگزینی، از مخزن فعلی و از داخل برنامه یک پشتیبان رمزگذاری‌شده بگیر.
2. فایل‌های ریشه سایت را با فایل‌های هم‌نام این بسته جایگزین کن: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
3. پوشه `google-apps-script` و فایل `Code.gs` را در مخزن عمومی منتشر نکن. `Code.gs` جداگانه در پروژه Google Apps Script قرار می‌گیرد.
4. پس از Commit و انتشار GitHub Pages، آدرس‌های `manifest.webmanifest`, `icon-192.png`, `icon-512.png` و `sw.js` را در مسیر `/journalnew1/` آزمایش کن.
5. در Chrome اندروید، داده‌های سایت را پاک نکن؛ ابتدا صفحه را Refresh کن. اگر نسخه قدیمی کش شد، از تنظیمات سایت فقط Service Worker را به‌روزرسانی یا سایت را یک‌بار در تب ناشناس آزمایش کن. حذف داده‌های سایت ممکن است داده‌های محلی ژورنال را پاک کند.

## نکته درباره قابلیت‌ها

منطق ژورنال، ذخیره‌سازی رمزگذاری‌شده محلی، Google Sheets JSONP، حفظ نشست و Passkey از آخرین فایل برنامه موجود در گفت‌وگو حفظ شده‌اند؛ تغییر اصلی این بسته رابط کاربری و PWA assets است. ورود Passkey همچنان به HTTPS و پشتیبانی واقعی مرورگر و احرازگر دستگاه از WebAuthn PRF نیاز دارد. در صورت نبود PRF، ورود با رمز عبور را استفاده کن.

اطلاعات معاملات و تنظیمات محلی در مرورگر ذخیره می‌شوند و به‌طور خودکار بین گوشی و کامپیوتر همگام نمی‌شوند؛ برای انتقال از پشتیبان رمزگذاری‌شده استفاده کن.
